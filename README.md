# SketchArena

A real-time multiplayer drawing and guessing game built with Next.js, TypeScript, Node.js, and Socket.IO.

Create a private room, invite friends, take turns drawing, and race to guess the word. The server owns round timing, scoring, drawing permissions, and reconnection state.

Implementation is being pushed in incremental feature batches. Setup instructions, architecture notes, tests, and deployment configuration are included as the application takes shape.
